po0fw

po0 防火墙白名单自动加白 —— 设备换 IP 后自动补白名单，覆盖软路由、PC、安卓、iOS 全平台。

服务端 /24 幂等加白 上限 5 坑 · FIFO 淘汰 · 自动自愈 直连官方 IP · 免分流配置 GitHub

01它怎么工作

token 在 po0 控制台机器详情页「防火墙」卡片 → 复制添加脚本 里，pgnfw_ 开头那串。一台机器一个 token。

① 触发

定时（10~15 分钟）+ 网络切换事件双通道

② 上报

向官方 IP 端点发一个 POST，无需客户端探测 IP

③ 加白

服务端按来源识别 /24 网段，重复上报幂等不占坑

④ 自愈

坑满 FIFO 淘汰，被挤掉的设备下个周期自动补回

02选择你的平台

点击卡片直达安装方式。家里有软路由的优先只装软路由：全家设备连 Wi-Fi 天然被覆盖。

03安装

最推荐的位置：能感知 WAN 拨号/重连事件，换 IP 秒级加白，另有 cron 每 10 分钟兜底。SSH 登录路由器执行：

curl -sSL https://raw.githubusercontent.com/kelenetwork/po0fw/main/openwrt/install-openwrt.sh -o /tmp/i.sh
PO0FW_TOKENS="pgnfw_你的token" sh /tmp/i.sh
验证：跑一次 po0fw 看输出；日志在 /tmp/po0fw.log。家宽出口建议钉固定槽位：token 写成 pgnfw_xxx@0（见下方 FAQ）。

Linux / macOS（root 装 systemd timer，否则写 crontab，每 10 分钟）：

curl -sSL https://raw.githubusercontent.com/kelenetwork/po0fw/main/install-linux.sh | PO0FW_TOKENS="pgnfw_你的token" sh

Windows（管理员 PowerShell，注册计划任务：10 分钟 + 网络事件双触发）：

irm https://raw.githubusercontent.com/kelenetwork/po0fw/main/windows/install-windows.ps1 -OutFile i.ps1
powershell -ExecutionPolicy Bypass -File i.ps1 -Tokens "pgnfw_你的token"
常用命令：po0fw 立即加白 · po0fw status 只看白名单 · 改 token 编辑 /etc/po0fw.conf（Win：%ProgramData%\po0fw\po0fw.conf）

安卓代理客户端没有 iOS 那样的脚本引擎；加白只是一个 POST 请求，用自动化 App 做更简单且不挑代理客户端。

方案一 · MacroDroid（推荐，免 root）

建 2 个宏，动作都是「HTTP 请求」，方法 POST，URL：

https://124.221.69.228/api/firewall/pgnfw_你的token/add

宏 1：触发器「网络连接变化」（Wi-Fi + 移动数据都勾）→ 切网即时加白
宏 2：触发器「定期触发 15 分钟」→ 兜底捕捉静默换 IP（Wi-Fi 没断但公网 IP 变了 / 蜂窝换 IP），加「网络已连接」约束
装好后按引导关闭电池优化，否则后台被杀。

其他选择：HTTP Shortcuts（开源，定时 POST + 桌面小部件一键加白）；Termux 命令行党直接用 PC 的 Linux 一键脚本（自动识别 Termux 环境，装完 sv-enable crond）。

六大代理客户端脚本模块：带面板、蜂窝 📶 标记、network-changed 即时触发 + 每 10 分钟 cron。先在上方填 token，一键安装后参数已自动带上。

05FAQ

Wi-Fi 连着没断、公网 IP 变了（家宽重拨）能发现吗？
切网事件抓不到这种静默变更，靠定时兜底：各端 10~15 分钟周期照常上报。且家宽重拨大多在同一 /24 段内，本来就无需重新加白。真正的兜底主力是软路由 —— 它能感知 WAN 重拨事件秒级加白。
多台 po0 机器怎么配？
每台机器 token 不同，用英文逗号拼起来填一处即可（Shadowrocket / QX 用 |）：pgnfw_机器A,pgnfw_机器B。设备换 IP 后所有机器的白名单同时更新。
固定槽位 @N 是什么？
默认坑满按写入时间 FIFO 淘汰。家宽出口这种全家依赖的网段被挤掉几分钟都难受 —— 在 token 后加 @槽位号（0~4，自己指定）钉死：pgnfw_xxx@0，永不参与淘汰。注意：每个 IP 只占一个槽位，换槽位号前先去面板删旧记录；流动设备（手机/外出笔记本）别钉，靠自愈就够。推荐布局：家宽 @0，剩 4 坑留流动设备。
走代理会把代理节点 IP 加白吗？
一般不会：请求直连官方 IP 124.221.69.228，按域名分流的代理碰不到。iOS 模块已内置直连规则；TUN / 透明代理全局接管的场景加一条 IP-CIDR,124.221.69.228/32,DIRECT,no-resolve。软路由跑脚本时确认路由器自身流量不进代理链（OpenClash「绕过本机」等）。
白名单 5/5 满了？
不用管：FIFO 自动淘汰最旧的，被挤出的设备最迟一个周期自动补回。想保住关键网段用固定槽位。
token 安全吗？
token 即该机器的加白凭证，勿公开分享。本页填的 token 只存你浏览器 localStorage，不上传；仓库与模块不包含任何 token。
怎么卸载？
OpenWrt：rm /usr/bin/po0fw /etc/po0fw.conf /etc/hotplug.d/iface/99-po0fw 并删 crontab 中 po0fw 行 · Linux：systemctl disable --now po0fw.timer 后删相关文件 · Windows：任务计划程序删「po0fw」· 手机端：删对应模块 / 宏 / 自动化。
